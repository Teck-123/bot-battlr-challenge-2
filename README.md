# bot-battlr-challenge-2

- Bot Battlr is an interactive wec application where users can create, manage, and battle bots.

# Features

- Bot Army: Add, remove and view bots in your army.
- Bot Battling: Bots battle aganist each other and track results.
- Filtering & Sorting: filter the bots by attributes and sort them according to preferences.
- Interactive UI: the interface should manage bots and battle strategies.
- Data is stored in a local JSON server for testing.

# Technologies

- React.js, CSS
- JSON Server (local API)
- React useState & useEffect
- Vite
- Node.js
- Npm

# Installing

- npm create vite@latest bot-app
- cd bot-battlr
- npm install
- json-server --watch db.json --port 8001
- npm run dev 

# Conclusion

- When you open the browser, the available bots will appear, add the bots to your army using the "Enlist" button.
- Start the battles between the bots and wait for the end result.

- This application is meant to help you on understanding of creating a well functioning app using react.
